## Project Description
We are building a real Firewall by filtering packets to protect a network from unwanted network traffics. We will use VPS, a Virtual Machine server to run and test our firewall. We plan to cover this topics as our project demonstartions: 
* Default Deny
* Security Policy
* Network Zones
* Instrution detection

## Reproduce VPS setup
* Create a DigitalOcean Droplet (VPS).
* Write down the assigned IPv4 address.
* Open your Linux terminal and type this command: ssh root@SERVER_IP
* Enter the password created during the Droplet creation process.
* You should now access to your VPS.  through your terminal.
