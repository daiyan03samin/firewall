## Project Description

We are building and configure a Firewall by filtering incoming and outgoing network traffic to protect a network. We will use VPS, Virtual Private Server to run and test our firewall. We plan to demonstrate the following networking and security concepts:

* Default Deny
* Security Policy
* Network Zones
* Instrution detection

## Reproducing VPS Setup

* Create a new DigitalOcean Droplet (VPS).
* Copy the assigned IPv4 address.
* Connect to the VPS using ssh in Linux terminal: `ssh root@SERVER_IP`
* Enter the password created during the Droplet creation process.
* You should now access to your VPS through your terminal.
